# 贡献指南

本文档说明如何向 **Telegram-iOS 上游** 贡献代码。本仓库 `teamgram-ios` 为 Teamgram 定制 fork，重大功能通常在内部分支完成；修复构建、对接文档问题可直接提 PR 到本 monorepo。

---

## 上游接受的贡献

欢迎：

- Bug 修复
- 性能优化
- 文档改进（构建说明等）

**通常不接受**（上游政策）：

- 新功能、新 UI
- 新语言翻译（请用 [Translations 平台](https://translations.telegram.org)）
- 与 Telegram 产品路线无关的界面改动

Telegram-iOS 是 [Telegram 项目](https://telegram.org) 的一部分，功能与界面由官方团队规划。

## 同步上游

Fork 后请定期合并上游变更，避免 PR 冲突：

```bash
git remote add upstream https://github.com/TelegramMessenger/Telegram-iOS.git
git fetch upstream
git merge upstream/master
```

---

## Pull Request 要求

1. **一个 PR 只解决一个问题**
2. 多个 commit 建议 **squash 为一个**
3. 不要混入无意义的空白/格式改动
4. 保持改动最小、可读
5. **必须自测**编译通过
6. Commit 信息清晰说明原因

### Commit 信息示例

```
组件名: 简要说明

补充说明（可选）
```

## Teamgram fork 说明

对接自建服务端时，优先修改：

- `TeamgramGatewayHost.swift` — 网关 IP
- `build-system/*-configuration.json` — 包名与 API

后端文档：`teamgram/docs/`、`teamgram.io/enterprise/docs/`。
