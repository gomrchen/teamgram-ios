# 快速编译指南

面向 **本机开发**（模拟器或 Xcode 托管签名），使用仓库内 `teamgram-dev-configuration.json` 或自行复制的配置。

---

## 前置条件

- macOS 版本满足 `versions.json` 中 `macos`
- 安装 **Xcode**（版本与 `versions.json` 中 `xcode` 一致，或构建时加 `--overrideXcodeVersion`）
- 安装 **Bazel**（版本与 `versions.json` 中 `bazel` 一致）
- Python 3
- 已部署 Teamgram 服务端（见 `teamgram/docs/本地冒烟测试.md`）

---

## 1. 获取代码

```bash
cd <工作区>
# 本 monorepo 已包含 teamgram-ios，无需单独 clone
```

若从上游单独克隆，须带子模块：

```bash
git clone --recursive -j8 https://github.com/TelegramMessenger/Telegram-iOS.git
```

---

## 2. 申请 API 凭证

1. 打开 [obtaining_api_id](https://core.telegram.org/api/obtaining_api_id) 申请 `api_id` / `api_hash`
2. 写入配置文件（勿提交私密仓库外的生产密钥）

---

## 3. 准备 Apple 开发配置（真机）

1. 生成随机标识：`openssl rand -hex 8`
2. 在 Xcode 新建临时工程，Product Name `Telegram`，Organization Identifier `org.<随机串>`
3. 打开「钥匙串访问」→ 证书 → 查看 Apple Development 证书的 **组织单位（Team ID）**
4. 编辑 `build-system/template_minimal_development_configuration.json` 或复制为 `my-dev.json`：
   - `bundle_id`：`org.<随机串>.Telegram`
   - `team_id`：上一步 Team ID
   - `api_id` / `api_hash`：你的凭证

本仓库示例：`build-system/teamgram-dev-configuration.json`（`io.teamgram.Telegram`）。

---

## 4. 配置服务端 IP

编辑 `submodules/TelegramCore/Sources/Network/TeamgramGatewayHost.swift`，将 `ipv4` 改为你的 Teamgram 服务器局域网或公网 IP。详见 [服务端对接配置.md](服务端对接配置.md)。

---

## 5. 生成 Xcode 工程

在 **teamgram-ios 根目录**执行：

```bash
python3 build-system/Make/Make.py \
  --cacheDir="$HOME/telegram-bazel-cache" \
  generateProject \
  --configurationPath=build-system/teamgram-dev-configuration.json \
  --xcodeManagedCodesigning
```

首次运行会下载 Bazel 依赖，耗时较长。

---

## 6. 编译与运行

1. 打开生成的 `.xcodeproj`（路径见终端输出，通常在 `build/` 或 `Telegram.xcodeproj`）
2. 选择模拟器或已信任的真机
3. Product → Run

**仅模拟器、不需要描述文件**时可加：

```bash
  --disableProvisioningProfiles
```

---

## 7. 验证登录

- 服务端 `gnetway` 监听 10443 / 11443
- 测试环境验证码常为 **12345**（视后端配置而定）
- 失败时查看 Xcode 控制台与 `teamgram/logs/session.log`
